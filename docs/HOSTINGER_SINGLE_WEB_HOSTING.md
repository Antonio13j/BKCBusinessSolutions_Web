# Hostinger: plan Single Web Hosting

Referencia de infraestructura para `bkcsolution.com`, actualizada el 21 de agosto de 2026.

## Capacidades disponibles

El plan **Single Web Hosting** permite:

- Mantener un sitio empresarial completo con varias páginas, imágenes y videos optimizados, galerías, portafolio, blog y formularios externos.
- Utilizar hasta **10 GB de almacenamiento** y **100 GB de tráfico mensual**.
- Crear hasta **2 bases de datos**, **2 subdominios** y **2 dominios aparcados**.
- Utilizar **1 cuenta FTP**.
- Instalar una aplicación PHP o un CMS compatible, considerando que el plan está orientado a **un solo sitio principal**.
- Aprovechar **SSL gratuito activo**, CDN disponible, PHP 8.3 y copias de seguridad cada 7 días.

## Uso actual

El sitio consume aproximadamente **1 MB de los 10 GB disponibles**, por lo que existe suficiente margen para mantener y ampliar la web corporativa y el Portal de Acuerdos.

## Cuándo evaluar un cambio de plan

Se debería considerar un plan Premium o Cloud cuando sea necesario:

- Alojar más sitios web independientes.
- Atender un volumen de tráfico considerablemente mayor.
- Ejecutar aplicaciones o procesos que requieran más recursos del servidor.
- Aumentar la frecuencia o las capacidades de respaldo y recuperación.

Los límites y prestaciones deben verificarse nuevamente en Hostinger antes de tomar decisiones de infraestructura, ya que el proveedor puede modificarlos.
